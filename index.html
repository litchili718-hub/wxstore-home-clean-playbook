A · 基建动作

只播不店、频繁换链接，这一层不做好后面全白做

A1 · 品上全、上好、持续在售

商品力是货架的地基，拆成 5 个维度

维度手册要做什么家清怎么落
宽度在售 SPU 数、二级品类数拉齐其他电商平台容量 / 件数 / 适用范围全规格在售
价格力盘点有多少比例 SPU 有价格优势主力装逐款比价，优势为 0% 就报活动
爆款力盯 TOP5 SPU 的 GMV 占比，打造爆款链接囤货装、多件装做店内爆款链接
稳定性不频繁换链接，保持稳定在售家清同：换一次丢一次曝光与销量累积
佣金机制全店 100% 设置优选联盟佣金，盯达人动销达人带货 GMV、动销商品数一起看
A1 达标线6 条 · 逐条打勾

A2 · 引导用户收藏店铺

收藏店铺是货架上最强的用户召回场景，成本最低、复用次数最多

客服下单后、售后结束时各一句收藏引导
包裹卡印「收藏店铺」入口
直播间口播引导收藏

B · 必做动作

两个主力驱动：直播外溢、心智品

B1 · 直播后的成交与评价沉淀

直播给的是流量和成交基本盘，货架 / 搜索承接与直播规模正相关

1直播起量后连续 1–4 周盯货架 GMV（预期 ≥30%）
2没跟涨 → 回 A1 查主图 / 标题 / 评价是否齐全
3弱货架型商家：按直播规模倒推货架规模，设目标补缺口
4做直播后评价沉淀，使用平台「评价有奖」工具
B1 达标线6 条 · 逐条打勾

B2 · 心智品：应报尽报，报进去再投广放大

报入后既有价格转化，也带来搜索与推荐的额外曝光，配投广才能把体量放大

心智品额外 4 个曝光位
主搜品牌词、品类词搜索结果优先展示
小店与卡包「官方补贴 / 礼物」→「小店好货」tab
商详入口主图下入口；评价下 1 入口 + 3 推荐位
原生活动页「小店好货」活动页
B2 达标线4 条 · 逐条打勾

C · 优化动作

第三个驱动：搜索。用户在找，你有没有出现在他眼前

C1 · 搜索承接：主抓「小店与卡包搜」，其次「主搜」

先把自己的词表建起来，再逐个检查卡位

Step 1建词表按二级类目建月度候选词表：先品类词，再「品牌＋品类 / 规格」
Step 2查卡位逐词查主力款：是否曝光 / 排序 / 标题 / 价格 / 评价
Step 3改主图把点击率拉起来，按三条硬规矩改
主图三条硬规矩
1单主体、够大、别拼贴多图
2正品 / 售后 / 赠品可视化
3价格要有品类内竞争力
规格、用途、适用范围讲清楚（加分项）
属性 / 场景词增加 → 用匹配规格承接，标题主图可视化
品牌 / 型号词增加 → 查主力款搜索展示；新品类词增加 → 扩品参考
C1 达标线5 条 · 逐条打勾

执行节奏

什么时候做什么

每周 · 30 分钟
记货架 GMV 周环比
直播起量后跟 1–4 周看是否 ≥+30%
查有无链接被换、在售品被下架
每月初
5 维商品力记一次（SPU 数 / 价格优势比 / TOP5 占比 / 佣金动销）
更新二级类目候选词表
按活动节奏提报心智品，报后配投广
复核直播规模与货架规模匹配度，补缺口
抽 3–5 个主要搜索词查卡位 + 改主图
季度追踪
按 A / B / C 三层回溯，看落在哪一层
逐层往上推，不跳级

三条红线

做了等于白做

频繁换链接换一次丢一次曝光与销量累积
只播不店外溢流量全部漏掉
心智品报了不投广体量跃迁要靠投广
